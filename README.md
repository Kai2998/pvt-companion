# A Little Company — landing page

Plain HTML + CSS. No build step, no frameworks.

## Files
- `index.html` — the page
- `styles.css` — all styling
- `qr-telegram.svg` — QR code that opens https://t.me/kai2997
- `favicon.svg` — browser tab icon

## Host on GitHub Pages
1. Create a new repository on GitHub and upload all these files to the root (keep `index.html` at the top level).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.
